# Salty Fruit Studio

Portfolio site for [saltyfruit.studio](https://www.saltyfruit.studio).

Plain HTML + CSS, no build step.

- `index.html` — all content lives here
- `styles.css` — all styling; design tokens are CSS variables at the top

## Preview locally

Open `index.html` directly, or:

```sh
python3 -m http.server 4321
```

## Deploy

Any static host works (Vercel, Netlify, Cloudflare Pages) — point it at this
folder, no build command needed, then attach the `saltyfruit.studio` domain.
